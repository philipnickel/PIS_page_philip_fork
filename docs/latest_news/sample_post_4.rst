Description
-----------

We're excited to announce that all DTU Python courses now support Python 3.12! This update brings improved performance, better error messages, and new language features that will enhance your programming experience.

What's New in Python 3.12
--------------------------

**Performance Improvements:**
- **Up to 10% faster** execution for many programs
- **Improved memory usage** for large data structures
- **Faster startup time** for Python applications

**New Language Features:**
- **Better error messages** with more helpful suggestions
- **Improved type hints** for better code documentation
- **Enhanced f-string formatting** with new syntax options

**Library Updates:**
- **NumPy 2.0** with improved performance
- **Pandas 2.1** with new data manipulation features
- **Matplotlib 3.8** with enhanced plotting capabilities

Migration Guide
---------------

**For Students:**
- Update your Anaconda installation to the latest version
- Create a new environment with Python 3.12
- Test your existing code to ensure compatibility

**For Instructors:**
- Update course materials to reflect new features
- Test all assignments with Python 3.12
- Update environment specifications

Getting Started
---------------

1. **Update Anaconda**: `conda update anaconda`
2. **Create new environment**: `conda create -n py312 python=3.12`
3. **Install packages**: `conda install numpy pandas matplotlib jupyter`
4. **Test your setup**: Run a simple Python script
