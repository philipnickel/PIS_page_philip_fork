Description
-----------

Learn to create stunning data visualizations with Matplotlib! This hands-on workshop covers everything from basic plots to advanced customization techniques. Perfect for students presenting research data or creating publication-quality figures.

Workshop Topics
----------------

**Basic Plotting**
- Line plots and scatter plots
- Bar charts and histograms
- Customizing colors and styles

**Advanced Features**
- Subplots and figure layouts
- Annotations and text
- Export options (PNG, PDF, SVG)

**Best Practices**
- Choosing the right chart type
- Color accessibility
- Professional styling
